## Important unfinished risks

1. Full local Supabase/Postgres and Deno suites, concurrency and two-user RLS scenarios were not executable in this runtime (CLI/engine unavailable); the tests written here are not represented as passed.
2. The live snapshot is incomplete. Apply nothing to production until `docs/LIVE-ONLY.md` owner steps are completed and a reviewed schema diff is available.
3. The v2 UI currently deliberately fails closed when feature flag is off, and v1 RPC wrappers throw `use_payments_v2`. There is not yet a transparent live dual-stack compatibility window; deploy the tested backend and the matching UI together only after a confirmed maintenance plan.
4. SMM provider status/output schemas vary. `Partial` refund calculations and custom OAuth/signature templates need official docs and repeatable fixtures before enabling automated fulfillment/refunds in production.
5. Automatic USDT/Binance Pay verification is disabled. This must remain so until the Phase 5 evidence exists.
